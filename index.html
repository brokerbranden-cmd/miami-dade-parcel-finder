Distress signals

Foreclosures, tax deeds, unpaid taxes, code cases, liens and probate matched to each folio. Pick signals to see parcels with any of them.

Permits & code cases

Building permit history and city / county code cases matched to each folio. Pick any to see parcels with at least one. “No permit” is only used for cities whose permit history is public and 5+ years long.

Vacancy & condition

A "likely vacant / neglected" hint built only from public records: homestead and mailing address, neglect code cases, unsafe structures, expired or missing permits, tax delinquency and values. No utility data is published, so none is used.
